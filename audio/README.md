# audio/

Optional local soundtrack for the site.

- Drop audio files here (only music you have the rights to share — this folder is published publicly with the site).
- List them in `playlist.js` in play order. The site autoplays them in order on loop; the only control is a small play/pause button (M also toggles).
- Leave `playlist.js` empty for no soundtrack.
- Current soundtrack: 7 tracks — Ken Carson "overseas" first, then the six-track "Fivestar" set (Hevvi, twentythree, halfadedd), ~16 MB total.
